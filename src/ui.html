Mises à jour

Installer les mises à jour automatiquementComme Chrome : Volt télécharge et installe les nouvelles versions en fond, prêtes au prochain démarrage. Décochez pour ne chercher qu'à la demande.
Version installée : Volt ne cherche que quand vous le demandez.Les mises à jour viennent uniquement de la page GitHub du projet (Manasy9999/volt-browser). L'exécutable n'est pas signé : avant de l'installer, Volt vérifie qu'il est identique à celui publié (empreinte SHA-256). Vos onglets reviennent après le redémarrage.

Confidentialité

Bloqueur de pubs et traqueursuBlock Origin Lite : pages plus légères et plus rapides
Alerte sur les sites dangereuxPrévient avant d'ouvrir un site d'hameçonnage ou un téléchargement malveillant, grâce à Microsoft Defender SmartScreen : les adresses visitées lui sont envoyées pour vérification. Prend effet au prochain démarrage de Volt.
Proposer d'enregistrer les mots de passeVolt propose d'enregistrer vos identifiants quand vous vous connectez ; rien n'est enregistré sans votre accord. Désactivé, Volt ne propose plus d'en enregistrer, mais ceux déjà enregistrés restent remplis tant que vous ne les avez pas supprimés.
Gérer les mots de passeVoir, modifier, importer ou exporter vos identifiants enregistrés dans Volt
Cartes de paiementVos cartes enregistrées dans Volt, pour remplir les pages de paiement : chiffrées sur ce PC, sans le cryptogramme
Remplir les formulairesVolt retient ce que vous tapez dans les formulaires (nom, adresse, e-mail, téléphone) et vous le propose ensuite dans les champs. Jamais les mots de passe ni les cartes, gérés à part. « Effacer les données de navigation » vide aussi cette mémoire.
Supprimer les mots de passe enregistrésVide le coffre de Volt. Les cookies, l'historique et les autres données ne sont pas touchés.
Fenêtres surgissantesBloquées quand un site en ouvre sans que vous ayez cliqué. L'icône qui apparaît alors dans la barre d'adresse permet de les ouvrir, ou d'autoriser le site : les sites autorisés sont listés ici.

Cartes de paiement

Enregistrées dans VoltChiffrées sur votre PC. Sur une page de paiement, cliquez dans le champ du numéro de carte, puis sur l'icône de carte de la barre d'adresse : Volt vous montre le site qui va la recevoir, puis remplit le numéro, le nom et la date après Windows Hello (code PIN ou empreinte). Le cryptogramme n'est jamais enregistré : vous le tapez à chaque achat.
Aucune carte enregistrée.

Migration depuis un autre navigateur

Reprenez vos donnéesCookies (pour rester connecté à vos sites), favoris, mots de passe et historique, depuis un navigateur installé sur ce PC. Fermez-le d'abord, sinon ses fichiers sont verrouillés. Tout reste sur votre PC.
